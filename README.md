
# Turbo Test Cases

**A companion repository for [ACADE Turbo](https://www.acadeturbo.com/accounts/login/) - Free online turbomachinery meshing and SU2 simulation platform**

## What is ACADE Turbo?

[ACADE Turbo](https://www.acadeturbo.com/accounts/login/) is a free web-based platform that provides:
- **Automated mesh generation** for turbomachinery geometries
- **Online SU2 CFD simulations** with no local installation required
- **Simple post-processing** tools for analyzing results
- **AI assistant** for interpreting simulation results and troubleshooting

This repository provides validated test cases to help you get started with turbomachinery simulations on the platform.

## Repository Overview

Turbo_example collects and organizes classic turbine/blade row cases, providing references for designers and developers with similar simulation needs. Each case includes:
- Geometric design references and implementation data
- Representative validation papers
- Ready-to-use mesh generation configuration files
- SU2 calculation configuration files
- Mesh and simulation results

**Try these cases directly on [ACADE Turbo](https://www.acadeturbo.com/accounts/login/) - no software installation needed!**

## Getting Started

1. Browse the test cases in this repository
2. Sign up at [www.acadeturbo.com](https://www.acadeturbo.com/accounts/login/)
3. Upload the configuration files and run simulations in your browser (completely free)
4. Compare your results with the validation data provided here
